# World investigations

The current evidence is the [fresh simulation report](fresh/REPORT.md). It
includes new full-field runs, controlled interventions and native sensor
experiments. The report directory retains source snapshots and measurements;
the three `fresh_*.log` files record execution.

`historical_review/` preserves the earlier historical-only interpretation and its
superseded curation proposal. The root `historical_assays.json` and `checks.json`
also belong to that earlier pass. They are not fresh simulation results.

Registry availability is maintained separately in `registry/availability.json`
and uses only `preserved` / `eval-ready`. Scientific judgments here do not
automatically mark a world ready to run an evaluation.
