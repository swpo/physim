Physim studies whether AI agents can learn to predict unfamiliar physical systems through experiments.

Its worlds are interacting fields spread across space. Their dynamics produce persistent spots, moving structures, and collective behavior. An agent investigates a world through instruments, then submits a Python function that predicts what those instruments will measure under new experimental programs.

  1. Investigate a world

    Apply a source, move probes, and collect repeatable measurements.

  2. Build a predictor

    Turn observations into code that forecasts complete sensor readings.

  3. Test its predictions

    Compare predicted trajectories with independent realizations of the world.

A physical world with observable consequences

The worked world, p4g2_044, contains four activator fields and eight coupled channels. Localized structures coexist with extended stripe and defect patterns. A source can perturb these patterns; repositioning a probe changes which part of the response it sees.
