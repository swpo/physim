Investigate through experiments. Submit a function that predicts new experiments.

The agent gets an anonymous instrument interface, a Python workspace, and declared resource budgets. It chooses measurements and interventions, analyzes the resulting arrays, and saves predictor.py with any learned parameters or data.

One program, from a fixed starting point

An experiment specifies all actions and requested readings in advance. Timestamps are absolute from the prepared start. Starting another experiment restores that same physical state; ongoing noise differs independently between trials.

actions = [
    {"t": 1.0, "kind": "inject", "port": 2, "amp": 0.7, "dur": 4.0},
    {"t": 2.0, "kind": "adjust", "device": 1, "u": [0.2, -0.4, 0.1]},
]
queries = [
    {"sensor": "device0", "t": [0, 8, 12]},
    {"sensor": "device1", "t": [12, 20]},
    {"sensor": "global", "t": [20]},
]

This program injects through port 2 from time 1 to time 5, moves device 1 at time 2, and requests three sets of measurements. The source remains fixed when the probe moves. Actions may depend on earlier experiments, but cannot adapt to readings during this single program. The prediction API specifies the exact action ranges, timing rules, and output contract.

Explore, check, submit

OperationPurpose
experiment(actions, queries)Run one physical realization and receive the requested arrays.
usage()Read consumed and remaining experiment resources.
validate()Check a snapshot of the predictor against public interface requests. This provides no physical-accuracy feedback.
submit()Check and freeze the predictor and supporting files. Successful submission ends exploration.

The native agent tools expose these operations with a laboratory_ prefix. Experiment, model, and execution budgets are specified for each run; they are not properties of the physical world.

A deterministic predictor can repeat its estimate in every member. A stochastic predictor can return a non-Gaussian distribution. Repeating the same request with the same predictor seed must reproduce the output. Adding later actions or queries must preserve earlier predictions.

Evaluate the frozen artifact

The evaluator calls the submitted function on new programs in an isolated runtime without access to the experimental service. Forecasts are finalized before truth observations are loaded for scoring. Predictor seeds determine only the predictor's own sampling; they do not identify the world's noise.

The score compares distributions of measurements, including their dependence across times and sensor positions. A good result requires useful predictions under the selected interventions and probe movements.
