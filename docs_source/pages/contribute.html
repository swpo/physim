A useful contribution makes a physical system easier to reproduce, investigate, or evaluate.

Contribute a world

A preserved world needs its genome, a name, attribution, license information, and available provenance. Include recipes, simulator settings, observations, and known gaps where available. Any world can be preserved, including simple controls and historical examples; an apparatus or evaluation suite is not required.

Follow the world contribution guide to package the files with Blobkit and open a Hugging Face pull request. A maintainer reviews the submission; you do not need write access to the main dataset. For help packaging a world, start in the dataset's Community tab.

Contribute an evaluation suite

Eval-ready status applies to a validated preparation and suite. Add the exact starting state, numerical profile, measurement/control apparatus, reference trajectories, and validation evidence. The apparatus belongs to the preparation, and one world can support several preparations or suites.

Use interventions and observations grounded in the world's measured behavior. Fix score groups and coordinate scales before evaluating agents. Include controls that remove particular capabilities, such as responding to later pulses or tracking probe motion, and verify that the intended errors affect the score.

Record known measurement limits. Improvements to coverage should receive a new suite identity so existing results remain interpretable.

Contribute a predictor or result

Supply the executable predictor and supporting data, its observations, and exact world/preparation/suite references. Record model and harness settings, sampling, all resource budgets, stopping conditions, interface validity, and costs. Keep retries as separate attempts. Report scientific scores and framework outcomes separately, following the evaluation reporting rules.

Contribute code and documentation

Blobkit, world-generation research, and this website live in swpo/physim. The installed evaluation environment is being contributed to Prime Intellect's environments repository. During review the local environment remains available; after integration, the plan is to maintain the environment upstream and consume Blobkit as a versioned dependency.

The current public documentation is generated from docs_source/ by python3 scripts/build_docs.py. Edit those sources, rebuild, and run python3 scripts/check_docs.py. The older generators write to the research archive.

The installed environment supports the three eval-ready preparations listed in Evaluation, selected explicitly in evaluation configs. Contributions should preserve world, preparation, suite, and run identities and add evidence for any new physical coverage.
